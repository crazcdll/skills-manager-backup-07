# Flow01 · 纵向滚动与语义定位

> 执行类型：deterministic

## 落地入口

```
imeituan://www.meituan.com/mrn?mrn_biz=hotel&mrn_entry=hotelchannel-orderfill-duo&mrn_component=main&goods_id=1172344601&checkinDate={T+10:%Y-%m-%d}&checkoutDate={T+11:%Y-%m-%d}&biz_type=1&room_num=1
```

## 执行步骤

### S1. 页面加载确认

**操作**：无（通过 Scheme 进入页面）。

**等待**：页面加载完成（等待「房型详情」渲染）。

**校验**：
- 「房型详情」— 渲染就绪标志

### S2. 滚动到「入住人」模块

**操作**：向下滚动，找到「入住人」文案。

**等待**：滚动动画完成，目标文案可见。

**校验**：
- 「入住人」— 文案断言

### S3. 继续向下滚动查看更多

**操作**：向下滚动，找到「购买须知」文案。

**等待**：滚动动画完成，目标文案可见。

**校验**：
- 「购买须知」— 文案断言

### S4. 滚动到底部

**操作**：滚动到底部。

**等待**：底部内容加载完成。

**校验**：
- 「没有更多了」— 文案断言

### S5. 向上回滚验证

**操作**：向上滚动，回到「房型详情」。

**等待**：滚动动画完成。

**校验**：
- 「房型详情」— 文案断言
