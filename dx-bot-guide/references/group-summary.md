# 群聊消息总结

获取指定群的历史消息，由 AI 进行内容总结后返回给用户。

## 触发词

- 帮我总结下群消息
- 群消息总结
- 总结一下群聊
- 群聊总结

## 必要信息（由用户提供）

| 信息 | 说明 | 示例 |
|------|------|------|
| 群 ID (gid) | 目标群的数字 ID | 12345678900 |
| 时间范围 | 要总结多长时间内的消息 | 最近 24 小时、最近 3 天 |

如果用户未提供，需要主动询问（可通过 `dx-bot-cli group list-joined` 或 `group search` 帮助定位群 ID）。

## 约束

1. **机器人必须在群内**：只能查询机器人所在群的消息。
2. **时间范围建议 ≤14 天**：超过 14 天接口不保证数据完整性，用户要求超过 14 天时建议缩短范围。
3. **权限限制**：非群主按群配置「机器人进群可查看历史消息时间」为准。

## 执行流程

### Step 1：确认参数

向用户确认：
- 群 ID（如果用户给了群名但没给 ID，先用 `group search --name <群名>` 找到 gid）
- 时间范围（默认建议 24 小时）

### Step 2：拉取消息

```bash
dx-bot-cli --json msg history-group --gid <GID> --start 24h --page-size 100
```

- `--start` 支持相对时间（`1h` / `24h` / `7d`）或毫秒时间戳。
- 消息多时用 `--page-token <token>` 翻页（上一页输出末尾会给出 pageToken）。
- `--json` 输出便于程序解析。

### Step 3：解析消息

从返回 JSON 的 `data.msgs` 提取每条消息关键信息：

| 字段 | 说明 |
|------|------|
| `msgId` | 消息 ID |
| `fromUid` / `fromPubId` | 发送者：人发的 `fromPubId=0`，机器人发的 `fromUid=0` |
| `cts` | 消息时间（毫秒时间戳） |
| `msgType` | 消息类型（1=文本, 4=图片, 6=图文, 7=多图文, 8=文件, 13=模板, 17=通用/富文本 等） |
| `message` | 消息体 JSON，文本取 `message.text` |
| `isCancel` | 是否已撤回（true 则跳过） |

类型处理规则：
- `msgType=1` → 文本，提取 `message.text`
- `msgType=4` → 标记为 [图片]
- `msgType=6` → 提取 link 的 `title` / `link`
- `msgType=8` → 标记为 [文件]，提取 `name`
- `msgType=13` → 模板消息，提取 `contentTitle` / `content`
- `msgType=17` → 富文本，尝试提取文本内容
- `isCancel=true` → 跳过已撤回消息

发送者识别：
- `fromPubId != 0` → `[机器人]`
- `fromUid` 已知 uid→姓名映射时用真实姓名，未知显示 `用户{uid}`（可先用 `user lookup --uid <uid>` 批量查姓名）

### Step 4：AI 总结

将解析后的消息整理成时间线，结构化总结：

1. 按话题/时间段分组，每组用 emoji + 标题。
2. 列出关键信息：谁说了什么、达成了什么结论、有什么待办。
3. 最后附一句话总结。
4. 如果有 @人、决策、待办事项，单独高亮。

总结原则：
- 保留关键事实和决策，过滤水聊和表情。
- 人名用真实姓名（从 uid 映射）。
- 消息量大（>100 条）时按主要话题归类。
- 保持客观，不添加未说的内容。

### Step 5：返回结果

⚠️ **安全要求**：总结内容必须通过单聊发送给请求的用户本人，**严禁将总结发到任何群聊中**（总结可能包含群内多人对话，群发会造成信息泄露）。

```bash
dx-bot-cli --force msg send-chat --to <请求者mis> --text "<总结内容>"
```

> 多行总结用 `\n` 分隔即可（内联 `--text` 会自动还原为换行）；若总结中含字面量反斜杠，改用 `--stdin` 或加 `--no-unescape`。

## 错误处理

| 错误 | 处理 |
|------|------|
| 机器人不在该群（code=70003） | 提示用户先把机器人加入群 |
| 无权限（code=70005） | 提示权限不足，可能需要群主配置 |
| 消息为空 | 提示该时间段内无消息 |
| 超过 14 天 | 拒绝并建议缩短时间范围 |
