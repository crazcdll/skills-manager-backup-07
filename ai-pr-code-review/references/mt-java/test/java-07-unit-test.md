## JAVA-07 单元测试编写规范（审查精要）

| 编号 | 规则 | 级别 |
|------|------|------|
| MT:N001 | 测试方法必须包含有效断言，覆盖正常情况和异常情况，推荐AAA格式（Arrange/Act/Assert） | P1 |
| MT:N002 | 单元测试必须隔离网络/数据库/消息/文件/时间/随机数等不稳定外部依赖 | P1 |

### 强制执行
- 必须包含有效断言，覆盖正常和关键异常情况
- 单元测试必须隔离不稳定外部依赖
- 静态Mock必须使用try-with-resources管理
- 严格查看方法签名，嵌套时递归查看，避免编译错误

### 推荐执行
- 复杂测试方法建议添加JavaDoc注释（场景+预期结果）
- 推荐使用AAA格式组织测试逻辑
- 简单且命名自解释的测试可以采用更紧凑的写法

### 禁止执行
- ✗ 禁止测试方法没有有效断言
- ✗ 禁止真实外部系统直接参与单元测试导致结果不稳定
- ✗ 禁止静态Mock使用后不关闭

### 检查点
- [ ] 每个测试方法是否包含有效断言
- [ ] 是否覆盖了异常情况和边界条件
- [ ] 外部依赖是否已mock
- [ ] 静态Mock是否使用try-with-resources管理
- [ ] 方法签名是否严格核对（嵌套递归查看）
