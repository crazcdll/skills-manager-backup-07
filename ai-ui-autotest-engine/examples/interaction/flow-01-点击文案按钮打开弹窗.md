# Flow01 · 点击文案按钮打开弹窗

> 执行类型：deterministic

## 落地入口

```
imeituan://www.meituan.com/mrn?mrn_biz=hotel&mrn_entry=hotelchannel-orderfill-duo&mrn_component=main&goods_id=1172344601&checkinDate={T+10:%Y-%m-%d}&checkoutDate={T+11:%Y-%m-%d}&biz_type=1&room_num=1
```

## 执行步骤

### S1. 打开房型详情弹窗

**操作**：点击「房型详情」。

**等待**：弹窗加载完成。

**校验**：
- 「房型设施详情」— 渲染就绪标志

### S2. 查看房型详情弹窗内容

**操作**：无（已在弹窗中）。

**等待**：内容渲染完成。

**校验**：
- 「房型设施详情」— 文案断言

### S3. 关闭房型详情弹窗

**操作**：关闭弹窗。

**等待**：弹窗关闭。

**校验**：
- 「房型设施详情」消失 — 文案消失

### S4. 打开订房必读弹窗

**操作**：点击「订房必读」。

**等待**：弹窗加载完成。

**校验**：
- 「入离时间」— 渲染就绪标志

### S5. 查看订房必读弹窗内容

**操作**：无（已在弹窗中）。

**等待**：内容渲染完成。

**校验**：
- 「入离时间」— 文案断言
- 「预订提示」— 文案断言

### S6. 关闭订房必读弹窗

**操作**：关闭弹窗。

**等待**：弹窗关闭。

**校验**：
- 「入离时间」消失 — 文案消失
- 「预订提示」消失 — 文案消失

### S7. 打开费用明细弹窗

**操作**：点击「已优惠」。

**等待**：弹窗加载完成。

**校验**：
- 「费用明细」— 渲染就绪标志

### S8. 查看费用明细内容

**操作**：无（已在弹窗中）。

**等待**：内容渲染完成。

**等待**：弹窗关闭。

**校验**：
- 「费用明细」消失 — 文案消失
