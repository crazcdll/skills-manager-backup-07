## HA-04 存储高可用规范（审查精要）

| 编号 | 规则 | 级别 |
|------|------|------|
| MT:HA-S001 | 查询必须确保走索引（EXPLAIN验证≥range级别），IN ≤200，pageSize ≤200，深分页用游标 | P1 |
| MT:HA-S002 | 事务必须最小化且不含外部调用（禁止事务内RPC/MQ/文件IO），批量 ≤200，事务 ≤500ms | P1 |
| MT:HA-S003 | DELETE优先软删除，物理删除需二次确认+备份；DDL走RDS平台 | P1 |
| MT:HA-S004 | 连接池参数显式配置；写后读必须读主库；分库分表查询必须携带分片键 | P1 |

### 强制禁止
- ✗ 禁止事务内包含 RPC/MQ/文件 IO
- ✗ 禁止不带分片键的查询（分库分表场景）
- ✗ 禁止深分页直接使用 LIMIT offset, size（offset > 10000）
- ✗ 禁止 IN 元素超过 200 个
- ✗ 禁止应用程序执行 DDL
- ✗ 禁止连接池使用默认参数

### 检查点
- [ ] 查询SQL是否通过 EXPLAIN 验证
- [ ] 事务内是否包含外部调用
- [ ] 批量操作是否限制每批数量（≤200）
- [ ] @Transactional 是否在 public 方法且通过代理调用
- [ ] 连接池参数是否显式配置
- [ ] 写后读是否指定主库
- [ ] 查询是否携带分片键
