# Flow02 · gone 文案消失验证

> 执行类型：deterministic

## 落地入口

```
imeituan://www.meituan.com/mrn?mrn_biz=hotel&mrn_entry=hotelchannel-orderfill-duo&mrn_component=main&goods_id=1172344601&checkinDate={T+10:%Y-%m-%d}&checkoutDate={T+11:%Y-%m-%d}&biz_type=1&room_num=1
```

## 执行步骤

### S1. 弹窗关闭后文案消失

**操作**：点击「房型详情」，打开弹窗后关闭。

**等待**：弹窗关闭完成。

**校验**：
- 「房型设施详情」消失 — 文案消失（应通过：弹窗关闭后文案不再可见）

### S2. 另一个弹窗关闭后文案消失

**操作**：点击「订房必读」，打开弹窗后关闭。

**等待**：弹窗关闭完成。

**校验**：
- 「入离时间」消失 — 文案消失（应通过：弹窗关闭后文案不再可见）

### S3. 验证始终不存在的文案

**操作**：无（已在页面）。

**等待**：页面渲染完成。

**校验**：
- 「这是一个绝对不存在的文案」消失 — 文案消失（应通过：始终不存在的文案）

### S4. 验证始终存在的文案（预期失败）

**操作**：无（已在页面）。

**等待**：页面渲染完成。

**校验**：
- 「房型详情」消失 — 文案消失（预期失败：该文案始终存在，验证gone误判行为）

### S5. 滚动后验证文案移出视口

**操作**：滚动到底部。

**等待**：滚动完成。

**校验**：
- 「房型详情」不在视口内 — 视觉确认（应通过：顶部文案移出视口但未销毁）
