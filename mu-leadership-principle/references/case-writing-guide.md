## 一、案例收录标准（4条，须同时满足）

### 1. 符合词条内涵
案例故事需重点体现出 **1条** 领导力原则的 **2-3个** 相关内涵。

### 2. 案例结构清晰
案例结构尽可能按照 **STAR法则**（情景-任务-行动-结果）去体现，表达清晰，篇幅控制在 **800字以内**。

### 3. 来源可查证
为保证案例故事的真实性，需要提供 **可查阅的相关链接** 或者 **提报人信息**。

### 4. 脱敏处理
敏感信息（人物真实姓名、业务战略策略及具体数据等）须做脱敏处理。

## 二、案例结构（STAR法则）

### 必填字段

| 字段 | 说明 |
|------|------|
| **案例名称** | 用一句话概括案例故事及所体现的领导力原则 |
| **案例时间** | 时间是追溯案例发生背景的重要线索 |
| **案例提报人/渠道** | 留下提报人信息，方便对案例感兴趣的伙伴找到你 |
| **案例标签** | 格式：`#BG/BU/平台` `#词条` `#各序列` `#年份` |
| **案例故事** | 按STAR结构呈现（见下方） |

### STAR结构

| 要素 | 英文 | 说明 |
|------|------|------|
| **S** - 情景/背景 | Situation | 当时面临什么场景和背景？ |
| **T** - 任务/挑战 | Task | 面临的核心挑战或任务是什么？ |
| **A** - 行动 | Action | 采取了哪些具体行动？体现了哪些LP行为？ |
| **R** - 结果 | Result | 取得了什么成果？带来了什么影响？ |

## 三、编写建议（4条）

### 1. 内容真实，有共情点
通过真实业务场景、挑战建立链接，设置共情点。好的案例不仅传递领导力原则行为导向，还能引发读者共鸣——让读者认为这个案例跟自己有关，能从案例中看到自己的身影。

### 2. 态度鲜明，准确传递行为导向
面对情境中的挑战，通过人物的内心活动进一步阐释对领导力原则的理解，通过人物采取的具体行动展现出领导力原则倡导的行为导向。

### 3. 情节有起伏，语言生动
案例讲究冲突性和故事性。关键环节避免用概括性语言，必要时描述角色在情境下的对话和心理活动。可以适当运用形容情绪的词语，更能打动读者。

### 4. 信息脱敏处理
敏感信息包括：人物真实姓名、业务战略策略及具体数据等。须做脱敏处理。

## 四、审核流程（三审制）

| 步骤 | 负责人 | 审核重点 |
|------|--------|----------|
| **1审** | 初审人员 | 案例故事结构是否清晰，是否初步符合词条相关释义 |
| **2审** | 资深审核 | 词条是否符合核心内涵，能否复用于传播、讲师授课 |
| **终审** | 终审把关 | 全面复核是否符合案例标准，特别是有节点意义的案例是否可融入词条百科 |

- 提报案例的反馈会在 **一周内** 给出
- 不符合审核标准的案例可根据反馈修改后再次送审

## 六、FAQ

**Q1: 提报的案例一定要是标杆案例吗？bad case可以吗？**
不一定要标杆案例。如果能从bad case中加深对领导力原则的理解，还能体现出如何反思和指导正确工作，也期待看到这样的案例故事。

**Q2: 案例提报人必须是以团队名义提报吗？个人可以进行提报吗？**
当然可以。案例来源于项目组采访挖掘、团队提报以及领导力原则讲师认证过程中的案例分享，同样也面向个人收录相关故事。
