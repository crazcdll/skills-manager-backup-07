# Flow03 · 订单详情页弹窗新增文案行-布局与交互无遮挡

<!-- caseId = 4210288 -->

> 关联 EC 用例：4210288（P0：【订单详情页】弹窗新增文案行-布局与交互-无遮挡可交互）
> 执行类型：data-dependent
> 前置条件：已预订国内酒店订单，订单详情页可唤起号码呼出弹窗（展示态/编辑态）；美团App / 点评App

> 测试数据参考：EC 用例未提供具体订单号，执行时使用可联系酒店状态的国内酒店测试订单（见 workspace `testplan/testdata.md` 订单 #1）

## 落地入口

```
imeituan://www.meituan.com/mrn?mrn_biz=hotel&mrn_entry=hotelchannel-order-detail&mrn_component=hotelchannel-order-detail&order_id={order_id}&biz_type=1
```

## 执行步骤

### S1. 点击联系酒店唤起展示态弹窗

**操作**：点击「联系酒店」。

**等待**：号码呼出弹窗展示。

**校验**：
- 「将使用该号码加密呼出」 — 渲染就绪标志
- 「双卡双待请确认，系统呼出号码和下方一致」 — 文案断言

### S2. 检查展示态弹窗整体布局

**操作**：无（已在页面）。

**等待**：弹窗内容渲染完成。

**校验**：
- 「双卡双待请确认，系统呼出号码和下方一致」未遮挡号码区、「非本机号请修改」入口、「立即呼叫」「取消」按钮 — 视觉确认
- 弹窗无布局错位、「双卡双待请确认，系统呼出号码和下方一致」无截断换行异常 — 视觉确认
- 「为保证服务质量，您的通话可能被录音」 — 文案断言

**证据要求**：展示态弹窗整体截图一张（完整弹窗区域）

### S3. 点击非本机号请修改进入编辑态

**操作**：点击「非本机号请修改」。

**等待**：编辑态弹窗展示。

**校验**：
- 「输入本机号码」 — 文案断言
- 「双卡双待请确认，系统呼出号码和下方一致」 — 文案断言

### S4. 检查编辑态弹窗整体布局

**操作**：无（已在页面）。

**等待**：编辑态内容渲染完成。

**校验**：
- 「双卡双待请确认，系统呼出号码和下方一致」未遮挡「请输入本机号码」输入框、「立即呼叫」「取消」按钮 — 视觉确认
- 编辑态弹窗无布局错位、无文案截断 — 视觉确认

**证据要求**：编辑态弹窗整体截图一张（完整弹窗区域）

### S5. 点击取消关闭弹窗

**操作**：点击「取消」。

**等待**：弹窗关闭。

**校验**：
- 「输入本机号码」消失 — 文案消失

### S6. 再次唤起弹窗验证立即呼叫按钮热区

**操作**：点击「联系酒店」。

**等待**：号码呼出弹窗展示。

**校验**：
- 「立即呼叫」 — 文案断言
- 「立即呼叫」按钮点击热区与响应正常（可点击、非置灰禁用） — 视觉确认

> 备注：立即呼叫真实呼出验证归 Flow04（主链路回归），本 Flow 仅验证热区可交互；如执行环境不允许真实拨打，点击「取消」关闭即可。
