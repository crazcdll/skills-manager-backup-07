# 交易前端 AICoding 需求开发统计 Skill

从学城文档中读取 AICoding 需求开发统计数据，按业务线筛选并计算关键指标。

## 前置依赖

- `oa-skills citadel` CLI（已安装在全局）
- Node.js >= 18（使用 nvm 切换）

## 使用流程

### 1. 读取文档

使用 citadel skill 的 `getSimpleMarkdown` 命令读取学城文档内容：

```bash
export NVM_DIR="$HOME/.nvm" && [ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh" && nvm use 18 && oa-skills citadel getSimpleMarkdown --contentId <文档ID>
```

### 2. 解析数据

文档为表格结构，每一行包含以下关键字段：
- **方向**：业务线（酒店/到餐/服务零售/门票）
- **需求**：需求名称
- **研发同学**：负责人
- **需求人力**：整体投入 pd 数
- **开发状态**：已上线/测试中/开发中等
- **one-shot代码采纳率（%）**：AI 首轮生成可用代码占比
- **人工参与成本（pd）**：人工投入 pd 数
- **AI 提效（pd）**：AI 节省的 pd 数
- **AI 成熟度分析（L0~L3）**：需求的 AI 成熟度等级，取值为 L0/L1/L2/L3

### 3. 按业务线筛选

根据用户指定的业务线过滤数据。支持的筛选维度：
- 酒店
- 到餐
- 服务零售
- 门票

未指定业务线时，默认统计全部。

### 4. 计算统计指标

对筛选后的数据计算以下指标：

| 指标 | 计算方式 |
|------|----------|
| 需求总数 | 该业务线下的需求行数 |
| 有 one-shot 数据条数 | one-shot 采纳率字段不为空且不为"-"的行数 |
| 采纳率均值 | 所有有效 one-shot 采纳率的算术平均值，保留一位小数 |
| 有 AI 提效数据条数 | AI 提效字段不为空且不为"-"的行数 |
| 总计 pd 数 | 所有有效 AI 提效 pd 数的总和 |
| 成熟度占比（L0/L1/L2/L3） | 分别统计成熟度字段为 L0/L1/L2/L3 的需求条数 n，占比 = n / 需求总数，保留一位小数 |

**成熟度占比计算说明**：
- 分母固定为该业务线的需求总数（含成熟度字段为空的行）
- 成熟度字段为空、"-"或非 L0~L3 标准取值的行，不计入任何一级，但仍计入分母
- 四个等级占比之和可能小于 100%（若存在空值/异常值行），属正常情况，无需强行凑满 100%

### 5. 输出结果

按以下格式输出统计结果：

## [业务线名称]需求统计

**需求总数 X 个，有 one-shot 数据 X 条，采纳率均值 X%；有 AI 提效数据 X 条，总计 Xpd；AI 成熟度 L0 X% L1 X% L2 X% L3 X%**

| 指标 | 数值 |
|------|------|
| 需求总数 | X 个 |
| 有 one-shot 数据条数 | X 条 |
| 采纳率均值 | X% |
| 有 AI 提效数据条数 | X 条 |
| 总计 AI 提效 pd 数 | Xpd |
| AI 成熟度 L0 占比 | X% |
| AI 成熟度 L1 占比 | X% |
| AI 成熟度 L2 占比 | X% |
| AI 成熟度 L3 占比 | X% |

**详细数据明细：**

| 需求 | one-shot采纳率 | AI提效(pd) | 成熟度 |
|------|--------------|-----------|--------|
| 需求名称1 | X% | Xpd | L1 |
| 需求名称2 | X% | Xpd | L2 |
| ... | ... | ... | ... |

> 说明：摘要行中的成熟度占比按 L0/L1/L2/L3 固定顺序依次列出，百分比可保留一位小数或取整数，保持与原文档风格一致即可

## 示例

### 示例 1：统计酒店需求

用户输入：统计一下 https://km.sankuai.com/collabpage/2776216363 文档的酒店需求数据

输出：

## 酒店需求统计

**需求总数 8 个，有 one-shot 数据 6 条，采纳率均值 71.7%；有 AI 提效数据 6 条，总计 15.5pd；AI 成熟度 L0 0% L1 62.5% L2 25% L3 0%**

| 指标 | 数值 |
|------|------|
| 需求总数 | 8 个 |
| 有 one-shot 数据条数 | 6 条 |
| 采纳率均值 | 71.7% |
| 有 AI 提效数据条数 | 6 条 |
| 总计 AI 提效 pd 数 | 15.5pd |
| AI 成熟度 L0 占比 | 0% |
| AI 成熟度 L1 占比 | 62.5% |
| AI 成熟度 L2 占比 | 25% |
| AI 成熟度 L3 占比 | 0% |

## 注意事项

- 需求人力为 "-" 或空值的行仍需计入需求总数
- one-shot 采纳率为 "-" 或空值的行不计入采纳率均值计算
- AI 提效为 "-" 或空值的行不计入总计 pd 数计算
- 成熟度字段为 "-"、空值或非 L0~L3 标准取值的行不计入任何等级，但仍计入需求总数（分母）
- 合并单元格的行按实际业务线归属统计
- ~~删除线标记~~的数据为已废弃方向，根据用户需求决定是否纳入统计
