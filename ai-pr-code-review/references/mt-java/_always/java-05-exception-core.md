## JAVA-05 异常处理规范 — 核心审查精要（N001/N002/N007）

> 本文件仅提取路由表指定的 N001（异常使用）、N002（NPE防御）、N007（预检查）子集。

### MT:N001 异常使用规范

| 编号 | 规则 | 级别 |
|------|------|------|
| MT:N001 | 异常不得用于流程控制或条件判断，仅用于处理非预期错误 | P1 |

### MT:N002 NPE防御规范（P0）

| 编号 | 规则 | 级别 |
|------|------|------|
| MT:N002 | 必须防御NullPointerException，重点关注7类高风险场景 | P0 |

**7类高风险NPE场景**：
1. 基本类型包装类返回值（自动拆箱NPE）
2. 数据库查询结果
3. 集合元素（list中含null）
4. 远程调用返回值
5. Session数据
6. 级联调用（`a.getB().getC()`）
7. 并发集合操作（`map.get(key)` 后直接调用方法）

### MT:N007 可预检查异常规范

| 编号 | 规则 | 级别 |
|------|------|------|
| MT:N007 | 可通过预检查规避的RuntimeException（如NPE、IndexOutOfBoundsException）不应通过catch处理 | P1 |

### 强制禁止
- ✗ 禁止用异常做流程控制（如try获取文件判断是否存在）
- ✗ 禁止包装类自动拆箱不做null判断
- ✗ 禁止级联调用不逐级判空
- ✗ 禁止并发集合 `map.get(key)` 后直接调用方法（先判空或用 computeIfAbsent）

### 检查点
- [ ] 是否用异常做流程控制
- [ ] NPE高风险场景是否做了防御判断
- [ ] 级联调用是否逐级判空或使用 Optional
- [ ] 可预检查的异常是否错误地使用了catch
