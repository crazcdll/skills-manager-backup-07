# 常见 Type 速查

| 分类 | 常见 Type |
|------|----------|
| Transaction | `URL`, `System`, `OctoService`, `OctoCall`, `SQL`, `SQL.Conn` |
| Event | `SQL.Method`, `SQL.Database`, `OctoCall.appkey`, `URL.status` |
| Problem | `error`, `long-url`, `long-sql`, `long-call`, `Heartbeat` |

> 实时查询：`raptor types -a <appkey>` 可获取该服务实际上报的所有 type。
