# Flow02 · 语义定位

> 执行类型：deterministic

测试 tap-text 语义定位能力，覆盖精确命中、视口外滚动、变体文案、歧义多候选、不可点击节点五种场景。

## 落地入口

```
imeituan://www.meituan.com/mrn?mrn_biz=hotel&mrn_entry=hotelchannel-orderfill-duo&mrn_component=main&goods_id=1172344601&checkinDate={T+10:%Y-%m-%d}&checkoutDate={T+11:%Y-%m-%d}&biz_type=1&room_num=1
```

## 执行步骤

### S1. 精确文案命中

**操作**：点击「房型详情」。

**等待**：弹窗加载完成。

**校验**：
- 「房型设施详情」— 渲染就绪标志

### S2. 目标在视口外，滚动后点击

**操作**：点击底部「提交订单」按钮。

**等待**：滚动完成后，按钮可见并点击成功。

**校验**：
- 页面跳转到提单页 — 视觉确认

### S3. 文案变体

**操作**：点击「订房须知」。

**等待**：目标弹窗加载完成。

**校验**：
- 「入离时间」— 渲染就绪标志

### S4. 类似的文案多个

**操作**：点击第一个「预订」入口。

**等待**：目标加载完成。

**校验**：
- 页面跳转到对应模块 — 视觉确认

### S5. 不可点击节点

**操作**：点击「标准价」区域。

**等待**：价格详情区域加载完成。

**校验**：
- 价格详情区域展开 — 视觉确认
