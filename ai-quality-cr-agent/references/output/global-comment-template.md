## 字段说明

### 📆 审查范围（`{scope_label}`）

位置固定：在 **`**Review 结论：**` 之后、分隔线 `---` 之前**。由 `publish_results.py` 的 `scope_label(args)`（非 compact 形式）生成：

| 场景 | 实际输出 |
|------|---------|
| 全量 CR | `**审查范围：** 🟦 全量` |
| 增量 CR | `**审查范围：** 🟩 增量（从 \`7394fa3d\` → \`57c84425\`，5 个新 commit）` |
| 增量但 base/target 缺失 | `**审查范围：** 🟩 增量（5 个新 commit）` |
| 增量但无任何信息 | `**审查范围：** 🟩 增量` |

> commit hash 展示取前 8 位（`_short_hash()`），带反引号。

### 📦 基准 commit（末尾行）

> ⚠️ 本行必须是整条评论的**最后一行**。「无法行内锚定的 P0/P1」降级清单和「审查覆盖缺口」清单只允许出现在 `---` 分隔线之前，不得追加在基准 commit 行之后（下行正则扫全文，若后续文本含 40 位 hash 会干扰增量起点定位）。

> 🚨🚨 **【格式固定·勿改勿删勿调位置】** 🚨🚨
>
> 这一行是**下次增量 CR 读取起点的唯一依据**。下次 CR 会扫 PR 全部评论，用正则 `基准 commit:\s*([0-9a-fA-F]{40})` 拿到 `base_commit`。
>
> - **必须在整条评论的最末尾**（在 `📄 详细 Review 文档` 之后，后面不得再接任何内容）
> - **格式严格为** `📦 基准 commit: {40位完整hash}`（emoji + 空格 + 「基准 commit」+ 英文冒号 + 空格 + hash）
> - **用 40 位完整 hash，不是短 hash**（与上方「审查范围」里的 8 位短 hash 不同）
> - **`target_commit` 为空时整行（含前面的空行）不输出** —— 绝不允许输出 `📦 基准 commit: None` 或空值
> - 不得改成代码块、引用块、加粗或链接形式
>
> ℹ️ **读写不对称（刻意设计）**：写入侧严格带 `📦`（美观、便于人眼识别），但**读取侧正则不包含 emoji 也不要求标题**。因为 emoji 可能因平台渲染、复制粘贴或编码转换丢失，一旦依赖它去读，增量能力会静默失效。宽进严出。

**实例：**

```
📄 详细 Review 文档：https://km.sankuai.com/collabpage/xxxxxxxxx

📦 基准 commit: 57c844252774dd51f03353b7b7f387dcf801ef56
```

对应代码（`publish_results.py` · `assemble_global_comment()` 末尾）：

```python
# 【格式固定】末尾基准 commit 行是下次增量 CR 读取起点的依据，勿改勿删
target_commit = getattr(args, "target_commit", None)
if target_commit:
    lines.append("")
    lines.append(f"📦 基准 commit: {target_commit}")
```
