# Flow07 · 输入场景

> 执行类型：deterministic

测试 input-text 输入场景，覆盖输入框精确定位、预填文案清除、视口外滚动、目标不存在、纯文本输入等场景。

## 落地入口

```
imeituan://www.meituan.com/mrn?mrn_biz=hotel&mrn_entry=hotelchannel-orderfill-duo&mrn_component=main&goods_id=1172344601&checkinDate={T+10:%Y-%m-%d}&checkoutDate={T+11:%Y-%m-%d}&biz_type=1&room_num=1
```

## 执行步骤

### S1. 输入框精确语义定位

**操作**：在「联系人姓名」输入框中输入"张三"。

**等待**：输入完成后，确认输入内容已渲染。

**校验**：
- 「张三」— 文案断言（应通过：输入内容已正常显示）

### S2. 输入框存在预填文案

**操作**：在「手机号」输入框中输入"13800138000"。

**等待**：清空预填文案后输入完成。

**校验**：
- 「13800138000」— 文案断言（应通过：输入覆盖了预填文案）

### S3. 输入框在视口外

**操作**：滚动到底部后，在「发票抬头」输入框中输入"美团科技"。

**等待**：滚动到输入框位置并完成输入。

**校验**：
- 「美团科技」— 文案断言（应通过：输入内容已正常显示）

### S4. 输入框目标不存在

**操作**：在「备用联系电话」输入框中输入"13800138000"。

**等待**：系统返回目标不可达提示。

**校验**：
- 提示输入框不存在 — 逻辑断言

### S5. 纯文本输入

**操作**：在「备注」输入框中输入"请安排无烟房"。

**等待**：输入完成。

**校验**：
- 「请安排无烟房」— 文案断言
