# Flow04 · 断言组合与多条件验证

> 执行类型：deterministic

## 落地入口

```
imeituan://www.meituan.com/mrn?mrn_biz=hotel&mrn_entry=hotelchannel-orderfill-duo&mrn_component=main&goods_id=1172344601&checkinDate={T+10:%Y-%m-%d}&checkoutDate={T+11:%Y-%m-%d}&biz_type=1&room_num=1
```

## 执行步骤

### S1. 多条 present 全通过

**操作**：无（已在页面）。

**等待**：页面加载完成。

**校验**：
- 「房型详情」— 文案断言
- 「订房必读」— 文案断言
- 「已优惠」— 文案断言

### S2. present + gone 混合断言

**操作**：点击「房型详情」，打开弹窗。

**等待**：弹窗加载完成。

**校验**：
- 「房型设施详情」— 文案断言（present 应通过）
- 「房型详情」不在当前弹窗视口 — 视觉确认（gone 应通过）

### S3. 部分存在的断言组合

**操作**：无（已在页面）。

**等待**：页面渲染完成。

**校验**：
- 「漫曲」— 文案断言（应通过：存在的文案）
- 「这是一个绝对不存在的文案测试」— 文案断言（预期失败）
- 「房型详情」— 文案断言（应通过：存在的文案）

### S4. present + visual 组合

**操作**：点击「已优惠」，打开费用明细弹窗。

**等待**：弹窗加载完成。

**校验**：
- 「费用明细」— 文案断言（present 应通过）
- 弹窗标题、房费、优惠条目完整展示，弹窗无遮挡 — 视觉确认
