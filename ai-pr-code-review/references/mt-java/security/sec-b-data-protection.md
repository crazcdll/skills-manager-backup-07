## SEC-B 数据保护规范（审查精要）

| 编号 | 规则 | 级别 |
|------|------|------|
| MT:SEC-B001 | 用户输入输出前必须XSS转义（按上下文选择函数），敏感信息必须脱敏展示 | P0 |
| MT:SEC-B002 | 禁止通过GET参数传递长期认证Token（URL会被日志记录泄露） | P0 |
| MT:SEC-B003 | 禁止DES/MD5/SHA1等不安全算法，密钥禁止硬编码，安全场景必须用SecureRandom | P0 |
| MT:SEC-B004 | 反序列化必须用ObjectInputFilter白名单或JSON替代，禁止Jackson Default Typing | P0 |

### 脱敏规则速查

| 信息类型 | 处理方式 | 示例 |
|---------|---------|------|
| 鉴权信息（口令/密保） | 不允许展示 | — |
| 身份证号 | 仅显示首尾字符 | `3*****************1` |
| 手机号码 | 隐藏中间6位 | `134******48` |
| 地址 | 最多到"区"级 | 北京市朝阳区*** |
| 银行卡号 | 仅显示最后4位 | `************8639` |

### 算法安全速查

| 类别 | 禁止使用 | 推荐使用 |
|------|---------|---------|
| 对称加密 | DES, 3DES, RC4 | AES-256 (AES/GCM/NoPadding) |
| 哈希 | MD5, SHA1 | SHA-256 及以上 |
| 随机数 | `new Random()` | `new SecureRandom()` |
| 密钥管理 | 硬编码在源码中 | 密钥管理服务(KMS) |

### 强制禁止
- ✗ 禁止直接输出未经转义的用户输入
- ✗ 禁止通过 GET 参数传递长期认证 Token
- ✗ 禁止使用 DES/MD5/SHA1 等不安全算法
- ✗ 禁止密钥硬编码在源代码中
- ✗ 禁止对不受信任数据进行无防护的反序列化
- ✗ 禁止 Jackson 开启 Default Typing

### 检查点
- [ ] 用户输入输出前是否做了 XSS 转义
- [ ] 敏感信息展示是否做了脱敏处理
- [ ] 是否通过 GET 传递了长期 Token
- [ ] 是否使用了不安全算法
- [ ] 密钥是否硬编码
- [ ] 安全场景是否使用了 SecureRandom
- [ ] 反序列化是否有白名单或用 JSON 替代
