## HA-12 安全编码规范 — 认证与越权（审查精要）

> 本规范是认证与越权防护的唯一权威规范（SSOT）。

| 编号 | 规则 | 级别 |
|------|------|------|
| MT:HA-SEC001 | 所有对外接口必须配置认证拦截器或注解，删除/绕过认证等同接口裸奔（P0） | P0 |
| MT:HA-SEC002 | 必须防止越权：水平越权（查询条件必须含userId/tenantId）+ 垂直越权（权限校验后端独立执行） | P0 |

### 水平越权防护
- 用户 A 不能访问用户 B 的数据
- 查询条件必须包含当前用户标识（userId / tenantId）
- 建议：`SecurityUtils.checkOwnership(resource, currentUser)`

### 垂直越权防护
- 普通用户不能访问管理员接口
- 权限校验必须在后端独立执行，不能仅依赖前端隐藏按钮

### 强制禁止
- ✗ 禁止接口不配置认证就上线
- ✗ 禁止仅靠前端隐藏按钮实现权限控制
- ✗ 禁止在查询条件中缺少当前用户标识

### 检查点
- [ ] 新增接口是否配置了认证
- [ ] 是否存在仅靠前端隐藏的权限控制
- [ ] 数据查询是否包含当前用户标识（水平越权）
- [ ] 管理操作是否有额外的角色校验（垂直越权）
- [ ] CR 中是否标记了无认证/无越权的 P0 问题
