## SEC-C 访问控制与网络安全规范（审查精要）

| 编号 | 规则 | 级别 |
|------|------|------|
| MT:SEC-C001 | 文件路径必须toRealPath规范化+白名单校验+UUID重命名存储，禁止路径遍历 | P0 |
| MT:SEC-C002 | 网络请求必须防SSRF（内网IP白名单+DNS Rebinding防护）+设超时+HTTPS | P0 |

### 文件操作安全
- 上传文件必须白名单校验 MIME 类型 + 限制大小
- 上传文件必须重命名存储（UUID），禁止使用原始文件名
- 临时文件使用后必须及时删除
- 上传目录禁止执行权限

### SSRF 防护
- **禁止访问内网地址**：`10.*`、`172.16-31.*`、`192.168.*`、`127.*`、`169.254.*`
- 必须防范 DNS Rebinding 攻击（解析后二次验证 IP）
- 所有网络请求必须设置 connectTimeout + socketTimeout
- 涉及敏感数据传输必须使用 HTTPS

### 强制禁止
- ✗ 禁止文件路径未规范化就直接使用
- ✗ 禁止使用原始文件名存储上传文件
- ✗ 禁止上传文件不做 MIME 类型白名单校验
- ✗ 禁止网络请求访问内网地址
- ✗ 禁止网络请求不设置 connectTimeout + socketTimeout

### 检查点
- [ ] 文件路径是否做了 toRealPath 规范化
- [ ] 规范化后路径是否以基础目录开头（防路径遍历）
- [ ] 上传文件是否白名单校验类型 + UUID 重命名
- [ ] 网络请求目标是否做了白名单校验（防 SSRF）
- [ ] 是否禁止了对内网 IP 的访问
- [ ] 网络请求是否设置了超时
