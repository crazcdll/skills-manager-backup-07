# Flow09 · 输入框聚焦失焦与滚动联动

> 执行类型：deterministic

测试输入框的聚焦、输入、失焦（`blur-input`）完整生命周期，以及滚动后输入框定位的联动场景。

## 落地入口

```
imeituan://www.meituan.com/mrn?mrn_biz=hotel&mrn_entry=hotelchannel-orderfill-duo&mrn_component=main&goods_id=1172344601&checkinDate={T+10:%Y-%m-%d}&checkoutDate={T+11:%Y-%m-%d}&biz_type=1&room_num=1
```

## 执行步骤

### S1. 输入入住人姓名

**操作**：在入住人姓名输入框中输入中文姓名。

**等待**：输入完成。

**校验**：
- 输入框回显输入的姓名 — 视觉确认

**数据**：`{"anchor":"姓名","text":"张三"}`

### S2. 输入手机号

**操作**：在手机号输入框中输入 11 位手机号。

**等待**：输入完成。

**校验**：
- 输入框回显输入的号码 — 视觉确认

**数据**：`{"anchor":"手机号","text":"13800138000"}`

### S3. 锚点失焦

**操作**：点击锚点「订房必读」文案区域使输入框失焦。

**等待**：输入框失焦，键盘收起。

**校验**：
- 键盘已收起，页面恢复正常布局 — 视觉确认

**说明**：`blur-input` 以「订房必读」为锚点，在其附近找一个不可点击的纯文本节点点击，触发失焦。

### S4. 无锚点失焦

**操作**：再次聚焦手机号输入框，输入内容后使用无锚点的 `blur-input` 失焦。

**等待**：输入框失焦，键盘收起。

**校验**：
- 键盘已收起，页面恢复正常布局 — 视觉确认

**说明**：`blur-input` 无参数时，自动在视图树顶部附近找一个不可点击文案作为失焦目标。兜底坐标 `(92,685)`。

### S5. 重新聚焦并验证内容

**操作**：再次点击手机号输入框重新聚焦。

**等待**：输入框聚焦，键盘弹出。

**校验**：
- 输入框内容「13800138000」仍然保留 — 文案断言
- 光标重新出现 — 视觉确认
