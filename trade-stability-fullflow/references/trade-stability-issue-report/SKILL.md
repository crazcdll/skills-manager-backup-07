## 生成前置操作

在输出报告之前，**必须**先执行以下命令获取当前真实时间，用于填充报告中所有 `{生成时间}` 和时间线末行的时间戳：

```bash
date "+%Y-%m-%d %H:%M"
```

将命令输出结果（格式如 `2026-04-30 14:35`）赋值给 `REPORT_TIME`，后续在报告中替换所有 `{生成时间}` 占位符。

> ⚠️ 严禁使用估算或会话上下文中的推断时间，必须以 `date` 命令的真实输出为准。

### 提取各步骤完成时间和耗时

**【处置时间线】中每步的「完成时间」和「耗时」必须严格从对应步骤的输出标题中提取，不得估算或推断。**

各步骤输出标题格式如下，括号内即为需要提取的字段：

| 步骤 | 标题格式示例 |
|------|-------------|
| 第一步 | `✅ **第一步：信息提取结果**（完成时间：2026-04-30 14:23:05  耗时：约 3 分钟）` |
| 第二步 | `✅ **第二步：变更扫描结果**（完成时间：2026-04-30 14:28:12  耗时：约 5 分钟）` |
| 第三步（止损） | `🛑 **第三步：止损操作结果**（完成时间：2026-04-30 14:30:00  耗时：约 2 分钟）` |
| 第三步（跳过） | `🟢 **第三步：跳过止损**（完成时间：2026-04-30 14:28:15  耗时：约 1 分钟）` |
| 第四步 | `✅ **第四步【路径A】：告警排查结论**（完成时间：2026-04-30 14:46:33  耗时：约 18 分钟）` |
| 第五步 | `✅ **第五步：修复方案（xxx）**（完成时间：2026-04-30 14:56:59  耗时：约 1 分钟）` |

提取规则：
- **完成时间**：取标题括号内 `完成时间：` 后的时间字符串，精确到秒（`HH:MM:SS`），在时间线表格中显示时保留到分钟（`HH:MM`）
- **耗时**：取标题括号内 `耗时：` 后的字符串（如「约 3 分钟」），原样填入表格
- 若某步骤标题中缺少完成时间或耗时字段，填「—」，**严禁自行估算**

## ⚠️ 严格格式要求

> **以下格式规范为强制要求，不得省略、合并或改写任何章节。**

1. **【总结结论】必须输出为完整表格**，每行对应一个字段，不得改为文字段落。
2. **【处置时间线】必须输出为5列完整表格**（步骤 / 完成时间 / 耗时 / 操作内容 / 执行人），每步一行，不得省略列或合并行。**完成时间和耗时必须从对应步骤的输出标题中提取，严禁估算。**
3. **【详细排查信息】必须包含「告警/问题原始信息」「变更查询结论」「排查结论」「修复/通知信息」四个子章节**，以及「相关链接」汇总。
4. **所有 Markdown 标题层级统一**：报告标题 `##`，章节标题 `###`，子章节 `####`。

## 写入学城记录

将完整的报告写入学城 aHR0cHM6Ly9rbS5zYW5rdWFpLmNvbS9jb2xsYWJwYWdlLzI3NjY3NDQxNjE= 的子目录，文档标题格式为 `{问题标题} {YYYYMMDD}`。

### Step 1：确认 MIS 配置

`oa-skills citadel` 的认证依赖 MIS 账号，**一次配置后无需重复传 `--mis` 参数**：

```bash
# 读取已有配置
MIS=$(cat ~/.config/clawdgw.json 2>/dev/null | grep -o '"defaultUserId":"[^"]*"' | cut -d'"' -f4)
echo "当前 MIS：${MIS:-（未配置）}"
```

若 `MIS` 为空，立即向用户询问 MIS 并写入缓存：

```bash
mkdir -p ~/.config
echo '{"defaultUserId":"<YOUR_MIS>"}' > ~/.config/clawdgw.json
echo "✅ MIS 已缓存"
```

### Step 2：写入报告到学城

将报告写入临时文件后通过 CLI 创建子文档：

```bash
# 生成带时间戳的临时文件名（避免冲突）
REPORT_FILE="/tmp/stability_report_$(date +%Y%m%d%H%M).md"

# 写入报告内容到临时文件
cat > "$REPORT_FILE" << 'REPORT_EOF'
{此处放置完整的报告 Markdown 内容，包含总结结论、处置时间线、详细排查信息三个章节}
REPORT_EOF

# 创建学城子文档（parentId = 稳定性处置记录目录）
oa-skills citadel createDocument \
  --title "{问题标题} $(date +%Y%m%d)" \
  --parentId 2766744161 \
  --file "$REPORT_FILE" 2>&1

# 清理临时文件
rm -f "$REPORT_FILE"
```

> ⚠️ **必须用 `--file` 参数传入文件路径，不得用 `--content` 直接传多行 Markdown**，否则换行符会导致命令解析失败。

### Step 3：确认写入结果

命令成功后会返回新文档的 `contentId` 和链接：

```
✅ 文档创建成功
  标题：【点餐提单】xxx 处置报告 20260608
  链接：aHR0cHM6Ly9rbS5zYW5rdWFpLmNvbS9jb2xsYWJwYWdlL3h4eHh4eHh4eHg=
```

获得链接后，**将链接回填到「相关链接」表格和大象通知消息中**。

若写入失败（认证错误），执行以下命令重新认证后重试：

```bash
oa-skills citadel createDocument ... --force-ciba
```
