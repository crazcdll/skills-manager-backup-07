# Java常量定义规范

## 一、说明

本规范定义了Java常量定义和使用的标准，包含魔法值避免等内容。统一的常量定义能够提高代码的可读性和可维护性。

## 二、规则内容

### N001 [推荐] 魔法值建议避免

除字符串模板外，代码中不建议直接使用魔法值（未经定义的数值或字符串）。

**说明**：应该将数值或字符串定义为常量并统一维护，同时确保不定义逻辑相同但字面值不同的常量，以防止混淆和错误。

## 三、示例

以下示例仅用于说明规则边界与意图，不代表唯一实现方式；实际生成或审查代码时，应优先复用项目现有框架、工具类、SDK 与命名，并以是否满足规则约束为判断标准。

#### good case:

```java
private static final String SUCCESS_MESSAGE = "操作成功";
```

#### bad case:

```java
if (status == 1) { // 魔法值
    logger.info("状态为成功");
}
```

## 四、规范执行要点

- ✗ 不建议直接使用魔法值（如 `if(status==1)`，字符串模板除外）
- ✗ 不建议定义逻辑相同但字面值不同的常量（如 `SUCCESS="success"` 与 `OK="success"`）
