# Flow02 · 横向滚动与方向控制

> 执行类型：deterministic

## 落地入口

```
imeituan://www.meituan.com/mrn?mrn_biz=gcbu&mrn_entry=mrn-poidetail&mrn_component=poidetail&mrn_min_version=0.640.0&use_main_prefetch=true&id=1029213017629890
```

## 执行步骤

### S1. 进入页面，确认 Tab 栏

**操作**：无（通过 Scheme 进入页面）。

**等待**：页面加载完成。

**校验**：
- 「预订」— 渲染就绪标志

### S2. 向下滚动到日期选择区域

**操作**：向下滚动，找到「今天」文案。

**等待**：滚动动画完成。

**校验**：
- 「今天」— 文案断言
- 「09-14」— 文案断言
- 「周六」— 文案断言
- 「09-19」— 文案断言

### S3. 日期选择器向右滚动（查看后续日期）

**操作**：向右滚动，找到「09-20」日期。

**等待**：横向滚动动画完成。

**校验**：
- 「09-20」— 文案断言
- 「周日」— 文案断言

### S4. 日期选择器向左滚动（回到初始位置）

**操作**：向左滚动，回到「今天」日期。

**等待**：横向滚动动画完成。

**校验**：
- 「今天」— 文案断言
- 「09-14」— 文案断言
- 「周六」— 文案断言

### S5. 房型选择器向右滚动（查看更多房型）

**操作**：向右滚动，找到「VIP包房」房型。

**等待**：横向滚动动画完成。

**校验**：
- 「VIP包房」— 文案断言

### S6. 房型选择器向左滚动（回到起点）

**操作**：向左滚动，回到「精品小包」房型。

**等待**：横向滚动动画完成。

**校验**：
- 「精品小包」— 文案断言
