# 绩效自评官方指南（精华摘录）

> 来源：美团内部《如何做好绩效自评及绩效考核FAQ》，仅供 Skill 运行时参考

## 一、绩效管理理念

绩效管理理念体现了通过什么样的方式能够取得好的绩效表现。理解绩效管理理念能帮助我们更有针对性地做绩效总结。

## 二、绩效自评的两大模块

### 模块一：工作回顾

对当期重点工作/目标完成情况的回顾，需如实填写、客观总结。

**填写要素：**
1. **重点工作/目标**：列举主要工作（2~5条，非事无巨细），可参考团队目标
2. **完成情况**：与预期相比打等级（超出预期/达成预期/不及预期）
3. **具体描述**（可选填）：推荐 STAR 结构——
   - **S**ituation（情景）：什么背景下
   - **T**ask（任务）：承担了什么
   - **A**ction（行动）：采取了什么措施
   - **R**esult（结果）：最终实现了什么

**管理者额外关注——团队建设：**
1. 团队分工是否合理有序？跨团队合作是否顺畅高效？
2. 人才"进出上下换"（招聘、培养与保留、汰换）
3. 组织调优和提效（MM及以上）
4. 人才梯队建设（MM及以上）

### 模块二：个人总结

思考未来的提升方向，关注三方面：

1. **整体工作表现**：全年工作结果的概括性总结和提炼，整体亮点、暗点
2. **个人优势项和待提升项**：过去一年的成长与不足，可参考[美团领导力原则]总结，也可写LP以外内容
3. **未来展望**：下期工作展望 + 个人发展展望，明确期待便于与主管对齐

**管理者额外关注**：团队建设的亮点、暗点及未来展望。

## 三、Good/Bad Case 示例

### 工作回顾

**😄 Good case：**
- 重点工作/目标：支持M活动的系统开发及上线
- 完成情况：达成预期
- 具体描述：
  - 情景/任务：公司需要在10月底前开办线下活动M，需将D系统做二次开发，时间紧任务重
  - 行动：快速组建项目团队，明确职责分工，制定项目计划，要求进度精准到天，采取2个保障措施
  - 结果：人力风险和技术攻关风险被提前发现并解决，早于活动两周完成，预留了充分的用户验证时间

**😭 Bad case：**
- 缺少案例支撑："我认为全年的工作达到了预期"
- 一句话略过："我组织的M活动顺利开展了"
- 只聊心得体会："通过这一年的xx项目，我感到非常的xxx，我学会了xxx"
- 谈空话："我积极主动地在各种项目上和业务/平台内的团队合作"

### 个人总结

**😄 Good case：**
- 整体工作表现：在A/B/C方面都有不错表现，XXX能力得到提高，3个重点项目都突破了瓶颈
- 优势：1）对业务理解比较优秀 2）极度关注客户 3）搭建团队能力突出
- 不足：1）深潜不够 2）系统设计有待提高 3）时间管理能力有待加强
- 下期重点和成长期望：1）战略思维培养 2）加强授权 3）提升系统能力 4）希望承担XXX类型工作

**😭 Bad case：**
- "我觉得今年整体工作还不错，接下来要继续加油"

## 四、绩效等级说明

| 等级 | 描述 |
|------|------|
| 超出预期 | 全年绩效表现已超出当前岗位和职级的要求 |
| 达成预期 | 全年绩效表现已达到或基本达到当前岗位和职级的要求 |
| 不及预期 | 全年绩效表现未达到当前岗位和职级的要求 |

## 五、FAQ 要点

- **考核周期**：上一年1月1日-12月31日，全年综合评价
- **目标与绩效关系**：目标达成是重要输入但非全部，还综合评估岗位职责和LP实践
- **年度 vs 月/季度考核**：年度是全年综合评价，非月季度加总；长周期工作（竞争优势建设、组织能力、人才培养）更多在年度体现
- **转岗情况**：在考核截止日所在部门参与考核，自评综合转岗前后全年工作
- **系统操作**：在 ov.sankuai.com 填写，支持保存草稿、撤回修改
- **结果应用**：用于年度激励分配、发展及任用安排

## 六、自评小贴士

1. **想不起做了啥**：参考周报、述职、团队目标等信息
2. **做了很多不知怎么呈现**：对照期初目标，按项目/岗位职责/主要产出分类
3. **目标进展AI总结**：可通过自评页面的AI小工具勾选目标快速总结
4. **可复用已有内容**：述职材料、月/季度考核材料可简化填写
