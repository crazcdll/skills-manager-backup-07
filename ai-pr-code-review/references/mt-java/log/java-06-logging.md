## JAVA-06 日志记录规范（审查精要）

| 编号 | 规则 | 级别 |
|------|------|------|
| MT:N001 | 统一使用 log4j2.xml + XMDFileAppender + scribeAppender，非阻塞模式 | P2 |
| MT:N002 | 日志级别正确：ERROR=需人工介入的系统异常，WARN=可自动恢复，INFO=关键业务节点 | P1 |
| MT:N003 | 日志必须含traceId和关键业务标识，异常日志必须传入异常对象（禁止仅打印e.getMessage()） | P1 |
| MT:N004 | 日志中禁止输出密码/Token/完整手机号/身份证号等敏感信息，必须脱敏 | P0 |

### 日志级别速查

| 级别 | 适用场景 | 禁止用于 |
|------|---------|---------|
| ERROR | 需人工介入的系统异常（DB不可用/OOM/关键RPC失败） | 可预期业务分支 |
| WARN | 可自动恢复的异常（降级/重试成功/缓存miss回源） | 正常业务流程 |
| INFO | 关键业务节点（订单创建/支付完成） | 高频接口每次调用 |
| DEBUG | 调试信息 | 生产环境 |

### 脱敏规则

| 信息类型 | 处理方式 | 示例 |
|---------|---------|------|
| 密码/Token/密钥 | 禁止输出 | — |
| 手机号 | 隐藏中间6位 | `138****5678` |
| 身份证号 | 仅显示首尾 | `3***************1` |
| 银行卡号 | 仅显示最后4位 | `************8639` |

### 强制禁止
- ✗ 禁止使用 properties 格式日志配置文件
- ✗ 禁止使用阻塞模式
- ✗ 禁止生产环境不配置远程日志上报
- ✗ 禁止 ERROR 级别用于可预期的业务分支
- ✗ 禁止异常日志仅打印 `e.getMessage()` 而不传入异常对象
- ✗ 禁止在循环中打印日志
- ✗ 禁止日志输出密码/Token/完整手机号/身份证号

### 检查点
- [ ] 是否使用 log4j2.xml + XMDFileAppender + scribeAppender
- [ ] ERROR 日志是否用于正确场景
- [ ] 异常日志是否传入了异常对象（完整堆栈）
- [ ] 日志中是否包含关键业务标识
- [ ] 是否在循环中打印日志
- [ ] 日志中是否有未脱敏的敏感信息
