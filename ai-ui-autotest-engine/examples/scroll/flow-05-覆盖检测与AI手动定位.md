# Flow05 · 覆盖检测与目标查找

> 执行类型：deterministic

## 落地入口

```
imeituan://www.meituan.com/mrn?mrn_biz=hotel&mrn_entry=hotelchannel-orderfill-duo&mrn_component=main&goods_id=1172344601&checkinDate={T+4}&checkoutDate={T+5}&biz_type=1&room_num=1
```

## 执行步骤

### S1. 页面加载确认

**操作**：无（通过 Scheme 进入页面）。

**等待**：页面加载完成（等待「房型详情」渲染）。

**校验**：
- 「房型详情」— 渲染就绪标志

### S2. 滚动到底部查看「购买须知」

**操作**：向下滚动，找到「购买须知」文案。

**等待**：滚动动画完成，目标文案可见。

**校验**：
- 「购买须知」— 文案断言

### S3. 确认页面到底标志

**操作**：继续向下滚动到底。

**等待**：底部内容加载完成。

**校验**：
- 「- 没有更多了 -」— 文案断言

### S4. 向上回滚到顶部

**操作**：向上滚动，回到「房型详情」。

**等待**：滚动动画完成。

**校验**：
- 「房型详情」— 文案断言

### S5. 查找不存在的文案

**操作**：向下滚动，尝试查找「闪住」文案。

**等待**：引擎滚动至页面底部，确认「闪住」在当前页面不存在。

**校验**：
- 「闪住」— 文案断言（应查询不到，该页面无此功能，标记为正常缺失）

### S6. 回滚到顶部

**操作**：向上滚动，回到「房型详情」。

**等待**：滚动动画完成。

**校验**：
- 「房型详情」— 文案断言
