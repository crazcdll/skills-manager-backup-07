# Flow02 · 订单详情页修改弹窗-编辑态双卡引导文案展示

<!-- caseId = 4210286 -->

> 关联 EC 用例：4210286（P0：【订单详情页】修改弹窗-编辑态双卡引导文案-双态均展示）
> 执行类型：data-dependent
> 前置条件：已预订国内酒店订单，订单详情页可唤起号码呼出弹窗且可进入修改号码流程；美团App / 点评App

> 测试数据参考：EC 用例未提供具体订单号，执行时使用可联系酒店状态的国内酒店测试订单（见 workspace `testplan/testdata.md` 订单 #1）

## 落地入口

```
imeituan://www.meituan.com/mrn?mrn_biz=hotel&mrn_entry=hotelchannel-order-detail&mrn_component=hotelchannel-order-detail&order_id={order_id}&biz_type=1
```

## 执行步骤

### S1. 点击联系酒店唤起呼出弹窗

**操作**：点击「联系酒店」。

**等待**：号码呼出弹窗展示。

**校验**：
- 「将使用该号码加密呼出」 — 渲染就绪标志

### S2. 点击非本机号请修改进入编辑态

**操作**：点击「非本机号请修改」。

**等待**：修改号码弹窗（编辑态）展示。

**校验**：
- 「输入本机号码」 — 文案断言
- 「请输入本机号码」 — 文案断言

**接口断言**：`POST /hotelorder/v1/queryuserinfo.json`
- error.code=200，data.maskMobile 正常返回

### A1. queryuserinfo 接口返回校验

- 接口 `POST https://apihotel.meituan.com/hotelorder/v1/queryuserinfo.json` 返回 error.code=200

### S3. 查看编辑态弹窗双卡引导文案

**操作**：无（已在页面）。

**等待**：编辑态弹窗内容渲染完成。

**校验**：
- 「双卡双待请确认，系统呼出号码和下方一致」 — 文案断言
- 「双卡双待请确认，系统呼出号码和下方一致」位于「输入本机号码」标题下方 — 视觉确认
- 「立即呼叫」 — 文案断言
- 「取消」 — 文案断言

**证据要求**：编辑态弹窗整体截图一张，供样式走查对照 UI 稿 https://imd.sankuai.com/goto/WXY9Zrqp

### S4. 关闭编辑态弹窗

**操作**：点击「取消」。

**等待**：弹窗关闭。

**校验**：
- 「输入本机号码」消失 — 文案消失

### S5. 重新唤起弹窗切换回展示态检查文案

**操作**：点击「联系酒店」。

**等待**：号码呼出弹窗（展示态）展示。

**校验**：
- 「双卡双待请确认，系统呼出号码和下方一致」 — 文案断言
- 「将使用该号码加密呼出」 — 文案断言

### S6. 再次进入编辑态检查文案不丢失不重复

**操作**：点击「非本机号请修改」。

**等待**：编辑态弹窗展示。

**校验**：
- 「双卡双待请确认，系统呼出号码和下方一致」 — 文案断言
- 「双卡双待请确认，系统呼出号码和下方一致」仅出现一次（不重复） — 视觉确认
