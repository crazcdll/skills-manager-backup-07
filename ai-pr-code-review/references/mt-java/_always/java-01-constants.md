## JAVA-01 常量定义规范（审查精要）

| 编号 | 规则 | 级别 |
|------|------|------|
| MT:N001 | 魔法值禁用：代码中禁止直接使用未定义的数值或字符串（字符串模板除外） | P2 |
| MT:N002 | long类型赋值：数值后必须使用大写L，禁止小写l | P2 |
| MT:N003 | 枚举类型优先：固定范围的值必须使用enum而非int常量 | P2 |

### 强制禁止
- ✗ 禁止直接使用魔法值（如 `if(status==1)`）
- ✗ 禁止定义逻辑相同但字面值不同的常量
- ✗ 禁止long赋值使用小写l（如 `long time=123456789l`）
- ✗ 禁止用int常量代替枚举

### 检查点
- [ ] 是否存在魔法值（未定义的数值或字符串）
- [ ] 常量是否统一定义和管理
- [ ] long类型赋值是否使用了大写L
- [ ] 固定范围的值是否使用了enum
