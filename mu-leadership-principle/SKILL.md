## 工作流

### S1 面试评价
- **入口**：用户提供候选人信息或面试记录
- **步骤**：
  1. 确认目标岗位核心LP（3-5条），无指定则推荐
  2. 读取目标LP的行为描述（从 `references/lp-behavior-data.md`）
  3. 对照候选人表现，逐条匹配熟练/过度/不足行为
  4. 按 `references/scenario-templates.md` 模板1输出评价表
- **出口**：输出包含≥3条LP维度评价，每条有≥1个行为证据

### S2 人才盘点
- **入口**：用户提供被评估人信息或历史表现
- **步骤**：
  1. 确认评估范围（全部15条 or 指定原则）
  2. 读取相关LP行为描述
  3. 逐条评估，标注强项/弱项/均衡
  4. 按模板2输出盘点报告，含发展优先级建议
- **出口**：输出包含评分表+强弱项分析+发展建议

### S3 绩效反馈
- **入口**：用户提供反馈对象和反馈周期
- **步骤**：
  1. 确认需反馈的LP维度（强项+发展区各1-2条）
  2. 读取相关LP行为描述
  3. 按模板3输出反馈信，正面+发展各有具体行为证据
  4. 附带发展行动计划表
- **出口**：反馈信包含≥1个强项LP和≥1个发展LP，各有具体事例

### S4 发展计划
- **入口**：用户提供发展对象和LP短板
- **步骤**：
  1. 确认优先发展的LP（1-2条）
  2. 读取目标LP的行为描述+发展指引
  3. 从发展指引中为实践/他人/课堂三维各选取≥1条建议
  4. 按模板4输出IDP，含阶段检查点
- **出口**：IDP包含三维发展路径，每维≥1条具体行动+完成标志

### S5 激励表扬
- **入口**：用户描述要表扬的行为或事件
- **步骤**：
  1. 识别该行为对应的LP原则（自动匹配或用户指定）
  2. 读取该LP的熟练运用行为
  3. 按模板5输出表扬词，引用具体行为条目
- **出口**：表扬词包含原则名称+具体行为描述+影响

### S6 荣誉表彰
- **入口**：用户提供被提名人信息和奖项
- **步骤**：
  1. 确认需论证的LP（2-3条）
  2. 读取相关LP行为描述
  3. 按模板6，用STAR结构为每条LP写论证事例
  4. **确认门控**：输出前请用户确认事实准确性
- **出口**：提名材料包含≥2条LP论证，每条有完整STAR事例

### S7 团队培训
- **入口**：用户指定培训主题LP
- **步骤**：
  1. 确认培训对象、时长、人数
  2. 读取目标LP全部内容（释义+行为描述+发展指引）
  3. 按模板7设计工作坊方案
  4. 从案例中心（contentId: 1461280091）推荐相关案例
- **出口**：方案包含≥4个环节+准备材料清单+跟进计划

### S8 自评自查
- **入口**：用户要求LP自评
- **步骤**：
  1. 确认评估范围（全部15条 or 指定原则）
  2. 按模板8逐条引导用户自评（分数+事例+是否过度）
  3. 读取用户评低分原则的行为描述，辅助分析
  4. 输出诊断结果+优先发展建议
- **出口**：诊断结果包含强项/弱项/过度标注+下一步建议

### S9 原则释义
- **入口**：用户询问某条LP的含义
- **步骤**：
  1. 识别目标原则
  2. 读取该LP完整内容（释义+行为描述+发展指引）
  3. 按模板9输出词条解读卡
- **出口**：解读卡包含释义+核心内涵+行为速览+应用场景+发展资源

### S10 案例编写
- **入口**：用户提供案例素材或要求写案例
- **步骤**：
  1. 确认目标LP原则（1条主线+可选辅线）
  2. 读取 `references/case-writing-guide.md` 的收录标准和编写建议
  3. 读取目标LP行为描述，提取2-3个内涵点
  4. 按模板10用STAR结构编写案例，≤800字
  5. **确认门控**：输出前请用户确认事实和脱敏处理
- **出口**：案例符合4条收录标准+STAR结构完整+≤800字
