## JAVA-08 接口设计规范（审查精要）

> 本文件仅提取路由表指定的 N007（接口兼容性）子集。

### MT:N007 接口兼容性规范

| 编号 | 规则 | 级别 |
|------|------|------|
| MT:N007 | 接口升级必须保证向后兼容，禁止删除已有接口方法或字段，不兼容变更通过新增方法/字段实现，旧版本至少保留2个迭代周期 | P1 |

### 其他接口设计检查点（附带审查）
- [ ] 接口命名是否使用大驼峰，名称是否清晰表达业务功能
- [ ] 接口参数是否使用包装类型（禁止基本类型）
- [ ] 接口是否返回封装结果对象（禁止直接返回null）
- [ ] 对外接口是否支持幂等性
- [ ] 列表接口是否分页，单页 ≤100 条
- [ ] 接口是否抛出统一业务异常（禁止技术异常）

### 强制禁止
- ✗ 禁止删除已有接口方法或字段
- ✗ 禁止不兼容变更不做新版兼容
- ✗ 禁止旧版本立即下线（至少保留2个迭代周期）
