# DUO 协议踩坑记录与降级策略

> ⚠️ 以下是从实际使用中提炼的常见错误，每条都是真实踩过的坑。

## 踩坑记录

| # | 错误 | 正确做法 | 原因 |
|---|------|---------|------|
| 1 | 多 DUO 页面只处理了一个 | 子步骤 1 输出页面清单后逐页处理 | 遗漏页面 = 遗漏线上功能 |
| 2 | lowCode「已支持」就不改协议 | 仍需检查 props/埋点/events | 新 UI 可能需要新配置 |
| 3 | 只改 dataSourceMap 不改 logics | 接口改动配套检查 logics | 埋点事件可能需要同步更新 |
| 4 | materialId 自行编造 | 通过 CLI/MCP 查询或从现有文件复制 | 编造 ID 导致物料无法加载 |
| 5 | 自行阅读学城/PRD 文档作为输入 | 唯一输入是 spec/plan/tasks | 已有结构化文档，重复解读浪费上下文 |
| 6 | constData 用于 reqProps | constData 仅可在 struct 中使用 | 平台运行时限制 |
| 7 | logic 类型 URL 用 `/material/` 路径 | 必须用 `/logic/` 路径 | CDN 路径区分类型 |
| 8 | 使用高版本 Groovy 语法 | 严格使用 2.4.17 兼容语法 | 后端 Groovy 版本固定 |
| 9 | 字符串字面量未用单引号 | Groovy 中 `'字符串'` 才是字符串 | 表达式解析规则 |
| 10 | 拆分后不回查 | 拆分后逐文件与 protocol.json 对比 | 拆分工具可能有 bug |
| 11 | 一次性生成所有文件就结束 | 必须逐文件覆盖并标记改动项 | 无法追溯遗漏 |

## 常见失败与降级

| 失败场景 | 降级路径 |
|---------|---------|
| spec/plan/tasks 文件不存在 | 提示用户先完成前置步骤 |
| 协议文件目录不存在 | 向用户确认文件位置，不允许静默跳过 |
| CLI/MCP 查询不到物料 ID | 从 `materials.json` 备选，仍无则不使用该物料 |
| splits 工具执行异常 | 手动修正拆分结果，确保一致性 |
| Groovy 语法不确定 | 参考 case-study/CS-groovy-syntax.md 二次确认 |
| 仅涉及单个 DUO 页面 | 仍按完整流程执行，不简化步骤 |
