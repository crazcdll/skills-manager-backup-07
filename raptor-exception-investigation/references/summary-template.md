# 排查总结报告模板

排查完成后，**必须**按以下格式输出完整的排查总结报告。所有字段都需填写，不可省略。

---

## 输出格式

```
---
## 📋 排查总结报告

### 基本信息
| 字段 | 值 |
|---|---|
| 项目 | {bundleName} |
| 平台 | {platform}（iOS / Android / HarmonyOS） |
| App | {app}（美团 / 大众点评） |
| App 版本 | {appVersion} |
| Bundle 版本 | {bundleVersion} |
| 错误级别 | {level}（fatal / error / warn） |
| 告警量 | {count}（时间范围内） |

### 问题概述
{一句话描述问题：什么场景下，什么组件/模块，发生了什么错误}

### 根因
{具体根因描述，包括：哪行代码、什么原因、为什么会触发}

### 修复方案
{修复方案描述，包括代码改动示例}

### 影响评估
{是否影响用户功能，影响范围，是否有静默失败风险}

### ⏱️ 排查耗时
| 指标 | 时间 |
|---|---|
| 开始时间 | {START_TIME} |
| 结束时间 | {END_TIME} |
| 真实过去时间 | {X} 分 {X} 秒（总挂钟时间） |
| 等待用户输入 | {X} 分 {X} 秒（等待截图/确认的时间） |
| 实际花费时间 | {X} 分 {X} 秒（真实过去时间 - 等待时间） |
---
```

---

## 计时说明

**等待用户输入的时间**指：每次我输出截图/问题后，等待用户回复的时间段。具体计算方式：

- 每次发出截图请求或等待用户确认时，记录等待开始时间
- 用户回复后，记录等待结束时间
- 将所有等待时间段累加，得到总等待时间
- 实际花费时间 = 真实过去时间 - 总等待时间

本次排查中，等待用户输入发生在以下场景：
- 截图后等待用户查看并回复（如"继续"或发回截图内容）
- 需要用户提供额外信息时

如果整个排查过程中没有等待用户输入（全自动完成），则实际花费时间 = 真实过去时间。
