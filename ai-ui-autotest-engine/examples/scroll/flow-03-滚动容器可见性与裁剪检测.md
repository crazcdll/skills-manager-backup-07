# Flow03 · 滚动容器可见性与裁剪检测

> 执行类型：deterministic

## 落地入口

```
imeituan://www.meituan.com/mrn?mrn_biz=gcbu&mrn_entry=mrn-poidetail&mrn_component=poidetail&mrn_min_version=0.640.0&use_main_prefetch=true&id=1029213017629890
```

## 执行步骤

### S1. 页面加载确认

**操作**：无（通过 Scheme 进入页面）。

**等待**：页面加载完成。

**校验**：
- 「预订」— 渲染就绪标志

### S2. 向下滚动到日期选择区域

**操作**：向下滚动，找到「今天」文案。

**等待**：滚动动画完成。

**校验**：
- 「今天」— 文案断言（在视口内可验证）

### S3. 向右滚动到日期末尾

**操作**：向右滚动，找到最后一个可见日期「09-20」。

**等待**：横向滚动动画完成。

**校验**：
- 「09-20」— 文案断言（已在视口，不会标记为视口外）

### S4. 验证超出容器的文案被正确标记为视口外

**操作**：确认「09-20」已是最后一个日期，更远的日期（如「09-21」）未被 RN 预渲染。

**等待**：无。

**校验**：
- 「09-21」— 文案断言（应查询不到，RN 懒加载未渲染则不视为 bug）

### S5. 向左回滚验证容器裁剪解除

**操作**：向左滚动，回到「今天」文案。

**等待**：横向滚动动画完成。

**校验**：
- 「今天」— 文案断言（回滚后重新可见）
