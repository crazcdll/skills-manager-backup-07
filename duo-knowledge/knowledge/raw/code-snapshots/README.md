# raw/code-snapshots/

每个代码仓库对应一个 `.md` 文件，存放该仓库的**目录树 + 每个模块的一句话说明**。不存代码本身，只存结构。

## 文件命名规则

`{仓库名}.md`，例如：`duo-core.md`、`duo-builder.md`

## 文件格式

```markdown
# {仓库名} 目录结构快照

- 仓库地址：git.sankuai.com/xxx
- 快照时间：YYYY-MM-DD
- 对应版本/分支：master / vX.X.X

## 目录结构

{目录树，每个目录附一句话说明}

## 更新记录

| 日期 | 变更内容 |
| --- | --- |
```
