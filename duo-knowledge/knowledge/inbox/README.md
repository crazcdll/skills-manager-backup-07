# inbox/

知识草稿暂存区，供维护者本地整理使用。

## 用途

存放待归档的知识草稿。内容来源：
- 维护者从「DUO 知识库维护群」整理的有价值消息
- 维护者本地临时记录的知识片段

## 使用规则

- 文件命名格式：`YYYY-MM-DD-{简短描述}.md`
- 每个文件对应一条待归档知识
- 归档到 wiki/ 后删除对应草稿文件
- **此目录内容不作为正式知识，不供 Agent 读取**

## 草稿文件格式

```markdown
场景：（什么任务触发了这个发现）
发现：（具体知识内容）
建议归档：（wiki/ 下的哪个文件）
置信度：高 / 中 / 低
来源：（大象群消息 / 用户主动触发 / 维护者发现）
```
