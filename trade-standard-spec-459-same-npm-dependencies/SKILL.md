# 标准化-三端一致性改造

## 📋 工作流描述

1、将三个系统都兼容的依赖版本写在package.json中，从oh-package.json中删除。2、仅兼容鸿蒙，不兼容android/ios的依赖，使用在oh-package.json中。3、目标是一方面减少分端差异，另一方面避免android/ios依赖的版本较低导致底层使用非标桥。
